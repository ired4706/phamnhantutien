# HUNT_LOOT

## Summary
Danh sách loot vật liệu từ `data/items/hunt_loot.json` (dùng cho cơ chế rơi từ `fhunt`).

## What data this doc covers
- Toàn bộ item trong `hunt_loot.json` và các trường dữ liệu mô tả item.

## Data source (JSON files)
- `data/items/hunt_loot.json`

## Item fields (common schema)
- `id` / key: khóa item (vd: `thanh_da_cot`)
- `name`: tên vật phẩm
- `emoji`: emoji hiển thị
- `rarity`: cấp độ hiếm (`common`, `uncommon`, `rare`, ...)
- `description`: mô tả lore

## How this data is used (code)
- `src/utils/data/item-loader.js`: `ItemLoader.loadAllItems()` sẽ load và merge `hunt_loot.json` vào pool item chung, đồng thời gán `category="hunt_loot"`.
- `src/utils/game/item-drop-calculator.js`: `ItemDropCalculator.calculateHuntItems()` lọc item theo `category === 'hunt_loot'` rồi chọn item theo `rarity`.

## Notes / Edge cases
- `hunt_loot.json` hiện không có trường `value` trong schema item.
